# Pantalla "Registro de Usuarios"
Ajustar a los siguientes campos únicamente:
- Email
- Contraseña

# Pantalla de "Registro de Empresas"
## Sección "Información General"
- Tipo: "Persona Física" o "Persona Moral"
- Si es Persona Física:
  - Nombre
  - Apellido Paterno
  - Apellido Materno
  - Fecha de Nacimiento
  - RFC
  - CURP
- Si es Persona Moral
  - Razón social
  - Fecha Constitución
- De forma general
  - Nacionalidades
  - Correos
  - Teléfonos
## Sección "Actividad Vulnerable"
- Actividad (debe ser un catálogo)
## Sección "Ubicación"
- La estructura del domicilio debe ser:
  - Calle
  - EntreCalles
  - Referencias
  - NumeroExterior
  - NumeroInterior
  - Codigo Postal
  - Asentamiento (Catálogo)
  - Ciudad
  - Municipio
  - Estado
  - País
## Sección "Beneficiarios
- Debe ser posible agregar una lista de "beneficiarios controladores". Donde un "Beneficiario Controlador" debe tener:
  - Porcentaje Capital
  - Porcentaje Capital Indirecto
  - Porcentaje Voto
  - Es Control Efectivo
  - Descripcion Mecanismo
  - Documento Identificacion Url
  - Documento Control Url
  - Documento Comprobante Domicilio Url
  - Fecha Validacion Documentos
  - Es Extranjero
    - Fecha Inicio Estancia
    - Documento Migratorio Url
  - Actua Mediante Representante
  - Representante (Nombre)
    - Documento Identificacion
  - Es Pep
    - Cargo
    - Fecha Inclusión
  - Fecha de Verificación de Datos
  - Método de Verificación
  - Verificado por
